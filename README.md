### Featured project

**[Roubi Network Scanner](https://github.com/c-roubi/roubi-network-scanner)**
A dependency-free TCP network scanner with service identification and
structured reporting (console, JSON, CSV, self-contained HTML). Supports
single hosts, CIDR ranges, and target files; built with a typed engine,
a `src/` package layout, strict `mypy`, `ruff` linting, and a `pytest` suite
run through CI on every push.
